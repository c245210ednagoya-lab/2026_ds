# 私が思うおいしい緑茶ランキング



緑茶が好きなわたしが、綾鷹・お〜いお茶・伊右衛門・生茶の4種類を比較し、独自の視点でランキング形式に紹介します。

色んな観点から緑茶のの違い独断と偏見で分析します！

---

🍃 観点

それぞれのお茶を、以下の5つのポイントから評価します。

* 味：お茶本来の味わい
* 香り：飲むときに感じる香り
* 苦味：苦味の強さやバランス
* 後味：飲んだ後に残る味わい
* 飲みやすさ：日常的に飲みやすいか

---

🎯 CONCEPT

「いつものお茶を、自分の舌でランキング。」

同じ緑茶でも、商品によって味わいや香り、飲み心地には違いがあります。

4種類のお茶を比較することで、それぞれの個性を発見し、自分にとって一番好きなお茶を見つけます。
